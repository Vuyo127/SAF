# SAF
SAF, short for Student Accommodation Finder, is a platform that connects students looking for accommodation that have beds available. Students can search, compare, and apply for accommodation while res owners can list their properties, manage bed availability in real time, and accept or decline a student's application. 
Finding student accommodation is often a slow, informal process involving word of mouth, outdated listings and no clear way to check real time bed availability. SAF solves that by giving students a single place to search for accommodation, view details, and apply while giving res owners a simple way to list properties, keep bed counts accurate and manage applicants.

|Features|
For students:
- Browse and search available accommodation listings.
- View property details, photos, and number of beds available.
- Apply directly to a listing.
- Track application status.

For res owners:
- Create an account and list properties.
- Upload property details, photos, and pricing.
- Set and update the number of available beds.
- Automatically or manually close a listing once fully booked.
- Review student applications and accept or decline them.
- Manage multiple properties from one dashboard.

Admin:
- Moderates listings.
- Manages users.
- Resolves disputes.
